# MCR-Precip Paper Package

This directory contains the results-ready paper and the evidence controls needed to turn it into a submission. It does not claim that the planned experiments have already been completed.

This is **Paper A**, the computer-method and reliable-prediction track. Its contribution boundary relative to the AI4Science manuscript is defined in the [two-paper portfolio](../paper_portfolio.md).

## Draft states

- **Results-ready:** scientific question, methods, result slots and decision gates are defined.
- **Evidence-complete:** every primary claim is backed by a frozen artifact and independent observation audit.
- **Submission-ready:** results reproduced, references verified, figures/source data generated, author declarations complete and all manuscript tokens resolved.

The current package is **results-ready**. Search for `TODO-RESULT-`, `TODO-REFERENCE-`, `TODO-AUTHOR-`, `TODO-DATA-` and `TODO-CODE-` before any submission build.
