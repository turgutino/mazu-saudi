## Evidence strength vocabulary

- **Discovered:** stable pattern proposed by the discovery pipeline.
- **Associated:** relationship survives declared statistical controls.
- **Physically consistent:** independent diagnostics and timing agree with an interpretation.
- **Mechanistically supported:** multiple independent budgets/diagnostics and negative controls pass.
- **Causal:** prohibited unless a valid identification strategy or intervention is added.

## Result artifact contract

Every token replacement must record event catalogue version, representation manifest, regime atlas version, diagnostic source, confirmation status, statistical model and code commit. Exploratory results cannot be relabelled confirmatory after the confirmation set is opened.
