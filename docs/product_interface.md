# MAZU Atlas 产品界面与服务架构

## 产品定位

MAZU Atlas 是 MCR-Precip 的本地科研预报工作台。它借鉴参考工程的模型服务、场景切换、历史轨迹、知识溯源和报告工作流，但不继承“手工填写几十个指标后输出风险分数”的首页结构。

首页围绕一次可审计的预报任务组织：研究区域、起报时刻、1/3/6 小时时效、极端降水概率场、强度分位数、四专家路由、不确定性、选择性覆盖、数据可用性和运行轨迹。

## 科学边界

当前服务使用确定性 demo backend，其唯一作用是验证页面与 API 工程闭环：

- 所有响应显式返回 `mode=demo` 和 `scientific_evidence=false`；
- 页面持续显示 `DEMO / 非业务预报`；
- demo cells、概率、强度和路由权重均不能进入论文结果；
- 正式后端只有在加载冻结模型包、真实因果输入和数据版本后，才能切换模式；
- 独立雨量站等评估数据保持 `not_observable`，不能伪装成在线输入。

## API v1

| Endpoint | Purpose |
|---|---|
| `GET /api/v1/health` | 服务模式、模型加载和证据状态 |
| `GET /api/v1/config` | 区域、时效、模型与数据版本 |
| `GET /api/v1/forecast?region=...&lead_hours=...` | 概率场、分位数、路由、不确定性、数据状态和审计信息 |
| `GET /api/v1/events` | 当前演示任务的可审计运行轨迹 |

核心合同实现在 `src/mazu_saudi/service/forecast.py`，与 HTTP 框架无关；以后迁移到 FastAPI 或业务网关时无需改变前端响应结构。

## 本地启动

```bash
PYTHONPATH=src conda run -n ml python -m mazu_saudi.service.server \
  --host 127.0.0.1 --port 8765
```

浏览器访问 `http://127.0.0.1:8765`。页面不依赖外部 CDN、地图瓦片、LLM 或知识图谱，适合离线比赛演示。

## 参考工程中吸收与拒绝的内容

吸收：模型/数据降级状态、区域选择、场景历史、Agent 次级工作区、知识溯源、API 分层和本地演示能力。

拒绝：同日规则分数冒充预测概率、历史相似日冒充实时背景、测试集调阈值、缺测自动转零、规则置信度冒充统计不确定性、知识图谱占据核心预报首页。
