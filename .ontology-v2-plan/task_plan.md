# 解释证据图谱 2.0 重构计划

## 目标

把当前分裂的本体、统计图、文献层和前端手工图统一到一套可审计的解释证据语义中；
未经原始证据与人工审核的关系一律不具备因果解释资格。

## 阶段

1. **安全门禁**（complete）
   - 关闭手工机制边和未核验文献边的因果资格。
   - 增加回归测试，禁止待审核边声明因果资格。
2. **本体 2.0 状态与环境模型**（complete）
   - 引入阈值派生状态和统一证据环境。
   - 修复极端状态指标断链、季节环境范围冲突和地形量混用。
3. **统一机制与旧图迁移**（complete）
   - 为旧图节点建立本体 IRI 映射。
   - 统一机制受控词表，避免两套机制名称并存。
4. **可执行语义验证**（complete）
   - 将本体一致性和实例约束接入构建入口。
   - 扩展测试覆盖状态、上下文、证据资格和迁移边界。
5. **验证与提交**（complete）
   - 运行聚焦测试、相关套件和全量测试。
   - 分阶段提交范围明确的改动，保留用户已有删除。

## 决策

- 图谱只用于解释、证据检索和缺口披露，不进入预测特征。
- `ObservedHazardEvent` 必须依赖独立事件来源；极端气象状态不能冒充灾害事件。
- `eligibleForCausalExplanation` 默认且当前固定为 `false`。
- SWEET、CF、KWG分别负责概念、物理量名称、外部地理背景，不替代本地证据模型。
